# Homepage narrative specification

## Current implementation

The current homepage is `src/content/docs/index.mdx`. It presents an Archont561 GIS/geospatial engineering tagline, a hero image, links to the repository mosaic and GitHub profile, six generated repository tiles, and four focus areas: geospatial tooling, systems in Rust, Python data pipelines, and the self-updating site. These claims should remain aligned with owner-approved profile information.

The full content order below is a product target for future iterations, not a claim that every section currently exists.

## Content order

1. Identity and a one-sentence value proposition.
2. Primary actions: Explore my work and About/contact.
3. Three or four selected projects with outcomes.
4. Areas of focus linking to catalog filters.
5. Latest writing.
6. Collaboration/contact invitation.

Leave these unknown until supplied. Do not publish this questionnaire as final homepage copy.

## Requirements

- HERO-001: Explain work in plain language, not only a list of tools.
- HERO-002: Featured selection is editorial; stars do not determine it automatically.
- HERO-003: Each featured item describes the problem and the author's contribution.
- HERO-004: Outcomes must be supported or phrased qualitatively without invented metrics.
- HERO-005: Avoid rendering the entire GitHub inventory on the homepage.

## Acceptance

Review desktop and narrow layouts, heading hierarchy, CTA destinations and screen-reader reading order. Ask the owner to approve all identity and professional claims.
